# Schefter Bot launch film

The published demo is a 25-second, silent trade-workflow cut with an animated
group chat. It shows a waiver claim, a trade offer, recipient consent, provider
submission, and the group reaction. Its source and verification notes are in
[TRADE-CUT.md](TRADE-CUT.md).

The directory also retains a 39-second phone-only [clean cut](CLEAN-CUT.md) and
the original 54-second launch film.

The film uses fictional league events, synthetic participant details, and
scripted dialogue. The waiver alert and recap are generated by the bot's real
Python formatters. The conversational answers are illustrative, not captured
live model responses. No messages are sent while building the video.

## Build the trade demo

```bash
npm ci
npm run fixtures:trade
npm run check
npm run audio:trade
npm run render:trade
npm run render:trade:feed
```

`audio:trade` reads locally installed Messages sounds, which are not licensed or
redistributed by this project. The published release is silent. Use only audio
you have permission to distribute; see [TRADE-CUT.md](TRADE-CUT.md).

## Build the archived launch film

From this directory, with Node.js 22+, npm, Python 3.10+, FFmpeg, and Chrome:

```bash
npm ci
npm run fixtures
npm run audio
npm run check
npm run stills
npm run render
npm run render:feed
```

The fixture generator imports the parent repository's Python feature code and
does not load `.env` or call external services. Audio mastering requires the
`ffmpeg` executable on PATH. Chrome is detected in its standard macOS location;
elsewhere set `REMOTION_BROWSER_EXECUTABLE` to your browser executable. Remotion
can download its browser when an executable is not supplied.

Archived-composition outputs (not tracked in Git):

- `out/schefter-bot-vertical.mp4`: 1080×1920, 9:16.
- `out/schefter-bot-linkedin.mp4`: 1080×1350, 4:5.
- Both are 30 fps H.264 / AAC, with a 54-second runtime.
- `out/Schefter*.png`: checkpoint stills for layout review.

Use `npm run studio` to preview and edit the compositions interactively.

## Edit the story

- `src/story.ts`: chat timing, line breaks, headlines, and scene copy.
- `scripts/build-fixtures.py`: synthetic league event data and real formatter output.
- `src/ChatPhone.tsx`: Messages-style UI, bubble motion, reactions, and scrolling.
- `src/LaunchFilm.tsx`: intro, layouts, diagrams, end card, and audio timeline.
- `scripts/compose-audio.mjs`: reproducible music and notification notes.
- `PRODUCTION.md`: creative direction, provenance, and truthfulness notes.

The displayed automated messages are checked against the generated fixture at
render time. If you change the fixtures, update the displayed lines to match.
